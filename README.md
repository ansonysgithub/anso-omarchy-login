# anso-omarchy-login

A Fallout-style **LOGIN** boot splash and login screen for [Omarchy](https://omarchy.org): a green-phosphor terminal look on a dark background.

![logo](logo.png)

- **Plymouth boot splash + SDDM login:** both are generated by `omarchy plymouth set` from `logo.png`, with background `#0b120c` and text `#1aff80`.
- **Update protection:** `omarchy-settings` owns `/usr/share/plymouth/themes/omarchy/` and `/usr/share/sddm/themes/omarchy/`, so package updates put the stock "Omarchy" screen back. A `NoExtract` line in `/etc/pacman.conf` stops that. (`omarchy-refresh-pacman` rewrites pacman.conf and drops the line, so re-run `install.sh` after it.)
- **Optional single-monitor splash:** on multi-monitor NVIDIA setups the splash can land on the wrong screen. `--single-splash` hides the other outputs on the kernel cmdline (`video=<output>:d`). `boot-screens-restore.service` then re-enables them before the login screen starts. The output names in `install.sh` (`DP-3`, `HDMI-A-1`) and the `card1-…` names in the service are specific to my machine. Check yours with `ls /sys/class/drm`.

## Install

```bash
git clone https://github.com/ansonysgithub/anso-omarchy-login.git && cd anso-omarchy-login && ./install.sh
```

Add `--single-splash` for the one-monitor splash. Revert to stock with `omarchy plymouth reset` and remove the `NoExtract` line.
